## IBRS ( IIT Bhilai Resource Sharing Platform )

- This platform was  created to help students share resources among themselves which helps reducing resource hunting time and saves mental stress.
- This platform uses React.js for frontend and uses redux for state management.
- Backend of this platform is based on node.js and express.js

### Deployment

- Frontend is deployed at netlify
- Backend is deployed at render


### How to use

- You can visit directly at [https://iitbh.netlify.app](https://iitbh.netlify.app/)
- ***You must know that backend is deployed on render, so it might take few minutes to boot up the backend, please be patient***
